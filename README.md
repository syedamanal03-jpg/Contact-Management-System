# Contact Management System

A console-based **Contact Management System** built in **C#** using a custom **Singly Linked List** data structure.

The project allows users to store and manage contact information while demonstrating fundamental **Data Structures and Algorithms (DSA)** concepts.

---

## Features

- Add a contact
- View all contacts
- Search contacts
- Update contact information
- Delete contacts
- Sort contacts
- Store contact data using JSON

Each contact contains:

- Name
- Phone Number
- Email

---
